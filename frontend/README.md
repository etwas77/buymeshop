# BuyMeShop Frontend

Frontend SPA built with React, TypeScript, Redux Toolkit, React Router, and Vite.

## Scripts

In the project directory, run:

### `npm run dev`

Starts the Vite development server on http://localhost:3000.

### `npm run start`

Alias for `npm run dev`.

### `npm run build`

Builds the production bundle into the `dist` directory.

### `npm run preview`

Serves the built app locally for verification.

## Notes

- Static assets are served from the `public` directory.
- App source code is under `src`.
